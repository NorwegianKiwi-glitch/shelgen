Inkay v2 - cross platform MarkDown note taking application

Note taking application built using Typescript frontend and a Rust backend, styled with tailwindcss

📓➡️🦀

From a Flask prototype to a native rewrite

Inkay started life as a simple Python + Flask notes app. Inkay v2 tears that up and starts over: Rust Tauri backend for speed and safety, paired with a TypeScript frontend for a snappier, type-safe interface, fast note taking, reliable, and available wherever you write them.
