Sentinal - self-hosted SOAR for your homelab

Scans your Docker containers for CVEs, has AI explain the findings, and lets you approve, snooze, or refuse remediation from a web console.

⚙️➡️🐍

From an n8n workflow to real, tested code

Sentinal started as an n8n workflow prototype, wiring together webhooks and nodes to watch a homelab Docker host. This rewrite does the same job, scan, explain, wait for human input, log the outcome, as a proper Python service: a Flask console, a Postgres audit trail.

How it works

🔍

CVE scanning

Trivy checks every running container against known vulnerabilities.

🤖

AI-explained findings

Gemini turns raw CVE data into plain-language explanations.

🙋

Web UI or Discord

Approve, snooze, or refuse remediation from the web console alone, or mirror alerts and decisions into Discord, whichever you prefer.

🩹

One-click patching

Apply Patch pulls a verified, safe upgrade tag for the vulnerable image.

⬆️

Confirm-gated major upgrades

Bigger version bumps require explicit confirmation and a pre-upgrade backup.

⏰

Scheduled scans

Configurable periodic scanning, editable from the console, no restart needed.

📜

Audit trail

Every decision is logged to Postgres; the log can be archived, never hard-deleted.

🏠

Self-hosted

Runs on your own Docker host, e.g. CasaOS on a Raspberry Pi.
